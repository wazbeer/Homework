## Классы Product и Category

### Product
- `name` (str) — название товара
- `description` (str) — описание
- `price` (float) — цена
- `quantity` (int) — количество на складе

### Category
- `name` (str) — название категории
- `description` (str) — описание
- `products` (list[Product]) — список товаров
- `category_count` (class attribute) — общее количество созданных категорий
- `product_count` (class attribute) — общее количество товаров во всех категориях

При создании категории `category_count` увеличивается на 1, а `product_count` — на длину переданного списка `products`. 

## Магические методы (HW 15.1)

В проект добавлена поддержка строкового представления объектов (`__str__`) и возможность сложения продуктов (`__add__`).

### 1. Класс `Product`

* **Строковое представление (`__str__`)**:
  При вызове `str(product)` или `print(product)` возвращается строка в формате:
  `"Название продукта, X руб. Остаток: X шт."`
  *Пример:* `Samsung Galaxy S23 Ultra, 180000.0 руб. Остаток: 5 шт.`

* **Сложение продуктов (`__add__`)**:
  Реализована возможность складывать два объекта класса `Product` через оператор `+`.
  Метод возвращает суммарную стоимость всех единиц обоих товаров на складе (`float`).
  *Формула:* `(price1 * quantity1) + (price2 * quantity2)`
  *Пример:* `product1 + product2 -> 2580000.0`

### 2. Класс `Category`

* **Строковое представление (`__str__`)**:
  При вызове `str(category)` или `print(category)` возвращается строка в формате:
  `"Название категории, количество продуктов: X шт."`
  *Где `X` — это общее количество всех единиц товара на складе (`quantity`) во всех продуктах этой категории.*
  *Пример:* `Смартфоны, количество продуктов: 27 шт.`

---

### Примеры использования

```python
from src.category import Category
from src.products import Product

# Создание продуктов
product1 = Product("Samsung Galaxy S23 Ultra", "256GB, Серый", 180000.0, 5)
product2 = Product("Iphone 15", "512GB, Gray space", 210000.0, 8)

# Отображение продукта в виде строки
print(product1)
# Вывод: Samsung Galaxy S23 Ultra, 180000.0 руб. Остаток: 5 шт.

# Сложение продуктов (суммарная стоимость всех штук на складе)
total_value = product1 + product2
print(total_value)
# Вывод: 2580000.0

# Создание категории
category = Category("Смартфоны", "Описание категории", [product1, product2])

# Отображение категории в виде строки (сумма штук: 5 + 8 = 13)
print(category)
# Вывод: Смартфоны, количество продуктов: 13 шт.
```

## Наследование и ограничение типов (HW 16.1)

В проект добавлена иерархия классов на основе базового класса `Product`, а также строгие проверки типов при сложении товаров и добавлении их в категорию.

### 1. Классы-наследники

* **`Smartphone` (Смартфон)** — наследуется от `Product`.
  * **Дополнительные атрибуты:**
    * `efficiency` (`float`) — производительность;
    * `model` (`str`) — модель;
    * `memory` (`int`) — объем встроенной памяти;
    * `color` (`str`) — цвет.

* **`LawnGrass` (Трава газонная)** — наследуется от `Product`.
  * **Дополнительные атрибуты:**
    * `country` (`str`) — страна-производитель;
    * `germination_period` (`str`) — срок прорастания;
    * `color` (`str`) — цвет.

---

### 2. Ограничения и проверки типов

* **Строгая проверка при сложении (`Product.__add__`)**:
  Складывать через оператор `+` можно только объекты **одного и того же класса** (например, `Smartphone + Smartphone` или `LawnGrass + LawnGrass`).
  * При попытке сложить объекты разных классов (например, `Smartphone + LawnGrass` или `Smartphone + Product`) выбрасывается исключение `TypeError`.
  * Валидация выполняется через сопоставление точных типов `type(self) is type(other)`.

* **Проверка при добавлении в категорию (`Category.add_product`)**:
  В категорию можно добавлять только объекты класса `Product` и его наследников (`Smartphone`, `LawnGrass`).
  * При попытке добавить объект другого типа (строка, число, список и т.д.) выбрасывается исключение `TypeError`.
  * Валидация выполняется через `isinstance(product, Product)`.

---

### Пример использования

```python
from src.category import Category
from src.products import Smartphone, LawnGrass

# Создание объектов дочерних классов
smartphone1 = Smartphone(
    "Samsung Galaxy S23 Ultra", "256GB, Серый", 180000.0, 5,
    95.5, "S23 Ultra", 256, "Серый"
)
smartphone2 = Smartphone(
    "Iphone 15", "512GB, Gray space", 210000.0, 8,
    98.2, "15", 512, "Gray space"
)
grass = LawnGrass(
    "Газонная трава", "Элитная трава", 500.0, 20,
    "Россия", "7 дней", "Зеленый"
)

# Сложение товаров одного класса -> Успешно
total_smartphones = smartphone1 + smartphone2  # Вернет сумму стоимости на складе

# Попытка сложить товары разных классов -> TypeError
try:
    invalid_sum = smartphone1 + grass
except TypeError:
    print("Ошибка: нельзя складывать товары разных классов!")

# Добавление в категорию
category = Category("Смартфоны", "Категория смартфонов", [smartphone1])
category.add_product(smartphone2)  # Успешно (Smartphone является наследником Product)

# Попытка добавить не-продукт -> TypeError
try:
    category.add_product("Не продукт")
except TypeError:
    print("Ошибка: можно добавлять только продукты и их наследников!")
